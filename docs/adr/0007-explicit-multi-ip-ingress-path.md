# ADR-0007: 多公网 IP 时显式选择入口路径

- 日期：2026-09-08
- 状态：已接受

## 背景

一台服务器可能同时配置多个同网段公网 IPv4。Linux 对绑定 `0.0.0.0` 的 UDP/QUIC
服务会按路由选择回包源地址，可能出现客户端访问 `.18`、服务回包从 `.17` 发出的
路径。TCP 服务由 nginx 或内网转发时，客户端连接地址与本机监听地址也可能不同。

## 决策

脚本检测默认路由网卡上与默认源 IP 同 `/24` 的公网 IPv4。普通安装向导展示一个
“公网入口模式”选择：域名加解析到的本机 IP、域名加 `0.0.0.0` 默认回程，或直接
使用某个公网 IP。该选择同时决定订阅连接地址和 HY2、直连 XHTTP、Reality、公网
中继的本机监听地址。高级协议管理页可以单独修改监听地址，命令行提供
`--listen-address`。

## 备选方案

- 始终绑定 `0.0.0.0`：单 IP 简单，但多 IP UDP 会产生不对称回包。
- 只修改 DNS：要求用户控制 DNS，且不能表达 `18 入、17 出` 与 `18 入、18 出`
  两种意图。
- 每个协议分别询问：信息重复，对新手不友好。

## 后果

- 正面影响：多 IP 入口路径明确，订阅继续可以使用域名作为 SNI。
- 负面影响：多 IP 机器安装时增加一个必要选择。
- 风险与后续：检测按默认路由网卡的 `/24` 分组；非默认网卡或多前缀地址仍应使用
  高级设置显式填写。
